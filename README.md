# 우리 아이 미션 & 칭찬 스티커판

아이의 하루 공부 미션을 체크하고, 스티커 30개를 모으면 상품을 받는 칭찬 스티커판입니다.

- **단일 파일**(`index.html`) — 빌드 없음, 서버 없음. 글꼴(Google Fonts)만 외부에서 불러오고, 안 되면 기기 기본 글꼴로 보입니다.
- **기록은 이 브라우저에만** — 진행 상황은 서버로 보내지 않고 그 기기의 `localStorage` 에만 저장됩니다.
- **휴대폰 세로 화면** 기준으로 만들었습니다.
- 요일별 미션, 스티커 조정, 상품·제목 변경, 전체 초기화, 백업/복원은 화면 아래 **⚙️ 엄마 설정**(간단한 덧셈 확인)에서 할 수 있어요.

## 사용 팁

- 스티커는 하루에 1개, 그날 미션을 **모두** 체크해야 받을 수 있어요.
- 브라우저 기록을 지우면 스티커도 사라집니다. 엄마 설정 → **📥 파일로 저장** 으로 가끔 백업해 두세요.
